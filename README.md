# Dalamud Custom Repo

This repository hosts a Dalamud custom plugin repository via GitHub Pages.

## Publish target

Enable GitHub Pages from the `main` branch and the `/docs` folder.

The custom repository URL for Dalamud will then be:

```text
https://<github-user>.github.io/<repo-name>/repo.json
```

## Before first push

Replace `__BASE_URL__` in these files with your final GitHub Pages base URL:

- `docs/repo.json`
- `custom-repo/repo.json`

Example:

```text
https://gezimao.github.io/dalamud-custom-repo
```
