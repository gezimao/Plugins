Dalamud Custom Repository

这个站点用于托管 Dalamud 自定义插件仓库。

在 Dalamud 中添加的仓库地址应为：__BASE_URL__/repo.json

发布前请先将 repo.json 中的 __BASE_URL__ 替换为这个站点的真实地址。
